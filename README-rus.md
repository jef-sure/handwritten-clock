Часы с погодой на рукописном шрифте
===================================

![Часы с погодой на рукописном шрифте](./clock.jpg "Часы с погодой на рукописном шрифте")

[English version](./README.md)

Часы на ESP32 с экраном 320x240. Время, температура и название города написаны
рукописным шрифтом на кривых Безье: цифры времени перетекают одна в другую,
температура и город пишутся штрих за штрихом. Значок погоды собран из точек и
плавно перетекает из одного в другой.

[![Видео: включение часов](./video-start.jpg)](https://youtu.be/5kWO57Guf_s)

Это вторая версия часов 2021 года. Первая описана в
[статье на Хабре](https://habr.com/ru/articles/818873/) и осталась под тегом
`2021`. От неё идея и раскладка экрана, код написан заново.

# Что на экране

Сверху время, под ним погода: значок и температура, внизу название города.

  1. Цифры времени не сменяются, а перетекают одна в другую;
  2. Температура и название города пишутся пером, буква за буквой, слитно. В
     шрифте латиница, немецкие «ä», «ö», «ü», «ß» и русский алфавит;
  3. Значок погоды собран из точек. Когда погода меняется, точки одного значка
     перетекают в другой;
  4. Время днём серебряное, ночью медное. Переход начинается за полчаса до
     восхода или заката и заканчивается через полчаса после;
  5. Цвет температуры и значка погоды зависит от температуры: 23 градуса
     приняты за «комфортный» уровень, ниже цвет уходит в синий, выше — в
     красный;
  6. После включения три значка в верхней строке показывают, чего часы ещё
     ждут: знак WiFi — подключения, «Z» — времени из сети, «W» — погоды.
     Дождавшись своего, значок уходит.

Переходы значков погоды крупно:

[![Видео: значки погоды из точек перетекают один в другой](./video-dots.jpg)](https://youtu.be/bh8ax5zkCpk)

# Железо

Плата CYD (ESP32-2432S028), она же Cheap Yellow Display: ESP32 и экран 2.8"
320x240 на контроллере ILI9341. На ней всё уже соединено. Для другой платы
выводы задаются в `main/display.c`:

| Дисплей | Вывод |
|---------|-------|
| MOSI    | 13    |
| MISO    | 12    |
| CLK     | 14    |
| CS      | 15    |
| DC      | 2     |
| BLK     | 21    |

Кнопка — GPIO 0, на CYD это кнопка BOOT.

# Сборка

Нужен ESP-IDF 5.2 или новее. Собирал и проверял я под 5.5.4 и 6.0.1, на одной
плате, а под версиями от 5.2 до 5.4 не проверял. Компоненты, включая
[dgx](https://github.com/jef-sure/esp32-component-dgx) 0.4.9, скачает менеджер
компонентов.

    idf.py set-target esp32
    idf.py build
    idf.py -p /dev/ttyUSB0 flash monitor

Список часовых поясов делается при сборке из базы tz той машины, на которой
идёт сборка: скрипт `misc/generate_tzones.py` берёт её из
`/usr/share/zoneinfo`, а если такого каталога нет, из пакета Python `tzdata`.

# Настройка

Ни сети, ни ключей сервисов в прошивке нет: часы хранят их у себя в NVS, и
настройки переживают перепрошивку. Компьютер для настройки не нужен.

## Сеть

Часы, которые не знают сети, показывают QR-код. Он для приложения ESP BLE
Provisioning от Espressif, которое есть в Google Play и в App Store: приложение
читает код с экрана и по BLE присылает часам имя сети WiFi и пароль. Получив
сеть, часы перезапускаются и дальше работают без BLE.

## Страница настроек

Кнопка BOOT перезапускает часы в режим настроек. Длительность нажатия ничего
не значит. Часы подключаются к сети и показывают адрес страницы текстом и
QR-кодом:

![Экран настроек: адрес страницы QR-кодом и текстом](./settings-screen.jpg "Экран настроек: адрес страницы QR-кодом и текстом")

Страница ждёт 5 минут, потом часы возвращаются к работе. Закрывает её и
повторное нажатие кнопки. Вход в настройки на видео:

[![Видео: вход в настройки](./video-settings.jpg)](https://youtu.be/48G7s-aJNIw)

Сама страница:

<img src="./settings-page.png" alt="Страница настроек" width="320">

| Поле | Значение |
|------|----------|
| Openweathermap.org API key | Ключ для погоды. Бесплатный, выдаётся на [openweathermap.org](https://openweathermap.org/). Без него часы показывают только время |
| Guess location from IP Info | Определять место по IP-адресу через [ipinfo.io](https://ipinfo.io). Выключено, пока его не включат: ошибка в десятки километров для этого способа обычное дело |
| IP Info API key | Ключ ipinfo.io, нужен только для этого способа |
| Manual location | Место: координаты («52.52,13.40»), город со страной («Berlin,DE») или почтовый индекс со страной («10115,DE») |
| Name on the screen | Своё название места на экране. Пустое поле — название от сервиса |
| Manual timezone | Часовой пояс. Если он не выбран, часы находят его сами по месту |
| Host name | Имя в сети, под ним же часы отвечают как `<имя>.local`. До настройки это `weather-clock-` и три последних байта MAC-адреса |
| Clear WiFi data | Забыть сеть WiFi: часы снова покажут QR-код для настройки с телефона |
| Clear all settings | Забыть всё: сеть, ключи сервисов, место и его название. Нужно, когда часы отдают другому человеку |

Сохранённые настройки вступают в силу перезапуском.

Время приходит с pool.ntp.org, погода — с OpenWeatherMap каждые 5 минут.

# Как это сделано

Всё заметное на экране делает
[dgx](https://github.com/jef-sure/esp32-component-dgx), моя графическая
библиотека для дисплеев на микроконтроллерах: рукописный шрифт, письмо в темпе
пера, морфинг цифр и точечных значков, виртуальные экраны в 8 бит с таблицей
цветов. В её репозитории лежат
[примеры](https://github.com/jef-sure/esp32-component-dgx/tree/main/examples),
почти все собраны под ту же плату CYD.

Шрифт нарисован в редакторе
[hw-fonts](https://github.com/jef-sure/hw-fonts): буква в нём хранится как путь
пера, а не как контур.

Страница настроек — обычный HTML-файл `misc/index.html`. При сборке скрипт
`misc/split_to_template.py` нарезает его на куски по местам вроде
`%HOST_NAME%`, и часы отдают страницу по частям прямо из flash.

# Компромиссы

  1. Прогноза нет, только погода сейчас;
  2. Часовой пояс по ближайшему месту иногда ошибается там, где рядом пояс без
     летнего времени: Эль-Пасо получит пояс Финикса. Тогда пояс надо выбрать на
     странице;
  3. Буквы других языков с диакритикой в названии города пишутся без неё:
     «Kraków» как «Krakow». Иероглифов и арабского письма в шрифте нет: такое
     название будет написано частично или не будет написано;
  4. Страница настроек оформлена Bootstrap, и его файл CSS браузер загружает из
     интернета, с CDN: в часах его нет. Без интернета на телефоне страница
     работает, но выглядит как голый HTML;
  5. Страница без пароля. Она существует только после нажатия кнопки и только в
     локальной сети.

# Использованные сторонние ресурсы

  1. Значки погоды — шрифт [Weather Icons](https://github.com/erikflowers/weather-icons)
     Эрика Флауэрса, лицензия SIL OFL 1.1. Сам шрифт лежит в `misc`, в
     `main/fonts` — его часть, переведённая в код утилитой `font2c` из dgx;
  2. Разбор JSON — [mjson](https://github.com/cesanta/mjson), Cesanta, MIT,
     в виде компонента [jef-sure/mjson](https://components.espressif.com/components/jef-sure/mjson/).
